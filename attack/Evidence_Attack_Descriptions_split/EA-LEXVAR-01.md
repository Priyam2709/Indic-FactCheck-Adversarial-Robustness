# 5. EA-LEXVAR-01: Lexical Variation Evidence Perturbation

## 1. Metadata
- **Attack ID**: `EA-LEXVAR-01`
- **Attack Name**: Lexical Variation Evidence Perturbation
- **Category**: `evidence_attack`
- **Attack Target**: `corrupted_verdict`
- **Edit Granularity**: `word`
- **Strategy Type**: `lm_based`
- **Access Assumption**: Black-box retrieval, Black-box verification
- **Source Paper**: Alzantot et al. (2018); Liu et al. (2025), Sec. 5.2.2, Table 4

## 2. Description
This word-level attack substitutes salient words in the evidence sentence with semantically similar counter-fitted synonyms generated by masked language models (e.g., RoBERTa/BERT). The goal is to alter subtle evidence details to deceive the verifier into reversing its stance while preserving high sentence fluency and overall context.

## 3. Preconditions / Required Inputs
- `original_evidence` (Required): Ground truth evidence text.
- `claim_text` (Required): Claim text.
- `gold_label` (Required): Gold label (`SUP`, `REF`).
- `mlm_model` (Required): Masked language model (e.g., IndicBERT / RoBERTa).
- `wordnet_synonyms` (Optional): Thesaurus/WordNet resource for candidate filtering.

## 4. Procedure
1. Identify salient non-stopword tokens in `original_evidence`.
2. Mask salient tokens one-by-one and pass the masked evidence to a Masked Language Model (MLM).
3. Filter candidate replacements using cosine similarity of word embeddings to ensure semantic closeness.
4. Substitute the target token with the top candidate that causes the maximum drop in the correct verifier stance probability.
5. Re-evaluate fluency using an LM perplexity threshold.

## 7. Success / Validity Criteria
- **Fluency Rate**: High perplexity score preservation.
- **Verdict Shift**: Flip of prediction label (`SUP` → `REF`).

## 9. Failure Modes / Skip Conditions
- Skip if no suitable MLM or WordNet synonym database exists for the language.
- Skip if the sentence contains fewer than 3 substitute-eligible words.
